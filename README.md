# Omagenda

*Type a sentence, get an event. What's next, always in the bar.*

An [Omarchy](https://omarchy.org) shell plugin that brings the two ideas that made Fantastical famous, the menu-bar mini window and natural-language event entry, to the Omarchy desktop. Events are plain `.ics` files in a vdir you own; sync is delegated to pimsync or vdirsyncer.

**Status: planning.** Read `PLAN.md` for the product and design, `ARCHITECTURE.md` for the technical contract, and `AGENTS.md` if you are implementing it.
